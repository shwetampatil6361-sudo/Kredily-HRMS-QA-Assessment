# Kredily HRMS – QA Assessment

## Overview

QA assessment performed on the Kredily HRMS Android application.

## Testing Areas

- Manual Functional Testing
- Bug Reporting
- Mobile Automation
- API Testing
- AI-Assisted QA

## Manual Testing

20 test cases were designed covering:
- Positive scenarios
- Negative scenarios
- Edge cases

## Bug Reporting

Genuine defects identified during execution are documented
with reproduction steps, expected result, actual result,
severity, priority and evidence.

## Mobile Automation

5 important user journeys were automated using Appium.

## API Testing

3 accessible APIs were tested using Postman with positive
and negative scenarios.

## AI-Assisted QA

ChatGPT was used to assist with test scenario generation.
All AI-generated scenarios were reviewed and validated
against the application.

## Tools

- Java
- Appium
- TestNG
- Maven
- Postman
- Git
